# Study Hub

Two courses in one app, switched with the bar at the top:
- **Algebra 1 in 7 Days**: worked → faded → independent practice, mastery gates, spaced review, error diagnosis, Day 7 test.
- **Business Ch. 1–7**: summaries, flashcards, practice, calculations, exam mode, Weak Spots.

## Put it online with GitHub Pages
1. Create a new public repository on github.com (for example `algebra7`).
2. Click **Add file → Upload files**, drag in every file from this folder, and click **Commit changes**.
3. Go to **Settings → Pages**. Under **Branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute, your app is at `https://YOUR-USERNAME.github.io/algebra7/`.

## Install on iPhone
Open that link in Safari, tap **Share → Add to Home Screen**. It opens full screen and works offline.

## Updating
Upload the new `index.html`, and change `VERSION` at the top of `sw.js` (for example `hub-v6`) so phones pick up the change.

Progress is saved on each device. For Algebra, use **Back up or move progress** on the dashboard to move it between devices.
